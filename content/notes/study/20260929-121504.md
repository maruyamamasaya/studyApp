# コードフェンス

次の HTML は説明用コードで、ボタンとして実行されません。

```html
<button onclick="alert('実行されない')">サンプル</button>
```

# 生 HTML

次の記述も文字列として表示され、スクリプトは実行されません。

<script>window.__unsafeArticleExecuted = true;</script>

<img src="x" onerror="window.__unsafeArticleExecuted = true">
