# Wiki 風サイドバーとコンパクト一覧

## 調査

- Phase 1 の Astro レイアウト、ホーム、記事カード、5テーマ、生成 HTML テストを確認した。
- 未コミットの Obsidian 同期関連変更を確認し、ホーム説明文と共通 footer の変更を保持した。

## 実装

- ホームから eyebrow、見出し、同期方式の説明文を削除し、記事一覧を最初に表示するようにした。
- 全ページ共通の左サイドバーを追加し、content collection の path をフォルダー階層として表示するようにした。
- 記事カードを2列の大きなカードから、タイトル・タグ・日付を横一列に収めるコンパクトな1列一覧へ変更した。
- モバイルではページツリーを折りたたみ、記事一覧はタイトルと日付を優先する。
- 「ページツリー」の見出しを開閉操作にし、主要ナビゲーションを残したまま階層一覧だけを畳めるようにした。
- Wiki 記事だけ記事タイトルを小さくし、サイトヘッダーの高さ・ロゴ・テーマ選択も少しコンパクトにした。スマホではタイトルとヘッダーをさらに詰める。
- スマホの記事本文でコードブロックの最小幅に押されていた article grid item を縮められるようにし、横スクロールを解消した。
- Wiki 風の細い罫線、密度、選択状態を全5テーマに共通する構造として適用した。

## 検証

- `npm run check`、legacy の password gate / unique heading ID test、`git diff --check` が成功した。
- 生成 HTML で説明文の削除、ページツリー、階層ラベル、記事一覧を確認するテストを追加した。
- ブラウザーでデスクトップの1列一覧と階層、390px幅での初期折りたたみ、展開、記事遷移、active 表示、横 overflow なし、console error なしを確認した。
- ページツリー単体の開閉で主要ナビゲーションが残ること、デスクトップではサイドバー表示、390px幅では外側のサイドバーが閉じることを再確認した。
- Wiki記事タイトルはデスクトップ40px（Study記事67.2px）・スマホ24.8px、サイトヘッダーはデスクトップ53px・スマホ49pxで表示されることを確認した。
- 390pxと320px幅で本文・コードブロックを含め横 overflow なし、console errorなしを確認した。

## 残課題

- 記事数が大幅に増えた段階では、ページツリー内の検索やフォルダー単位の開閉を検討する。
