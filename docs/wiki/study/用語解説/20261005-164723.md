## Pushとは？

**Push（プッシュ）**とは、

> **ローカル（自分のPC）の変更をGitHubへアップロードすること**です。

### イメージ

```
自分のPC
コードを編集
     ↓
git push
     ↓
GitHubに反映
```

例えば、

- バグ修正
- 新機能追加
- README更新

などをGitHubへ反映するときに使います。
