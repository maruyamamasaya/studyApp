# 1. 概要

async / awaitは、通信などの待ち時間に他の処理を進めるためのPythonの構文です。async defでコルーチンという待機可能な処理を定義し、awaitでその完了を待ちます。PythonのCPU処理が自動的に並列になる機能ではありません。

# 2. 何のために使うか

検索API、Embedding API、LLM APIなど、待ち時間が多いRAG処理で同時要求を扱うために使います。イベントループという実行管理の仕組みが、待機中の処理を切り替えます。

# 3. 仕組み

async関数を呼ぶだけでは通常その本体は実行されず、コルーチンをawaitするかTaskとしてスケジュールします。独立した通信は同時に開始できますが、質問Embeddingの結果を使う検索など、依存する処理は順番が必要です。

# 4. 具体例

次のコードはPython標準ライブラリだけで非同期の待機を試せる例です。2つの処理を同時に開始し、約1秒で両方を待ち終えます。実際のTe社基盤では、sleepの代わりに非同期SDKの通信をawaitします。

~~~python
import asyncio

async def fetch(label):
    await asyncio.sleep(1)
    return label

async def main():
    values = await asyncio.gather(fetch("規程"), fetch("手順"))
    print(values)

asyncio.run(main())
~~~

# 5. 実装・設定時のポイント

- 非同期SDKを使う場合はクライアントの終了処理も確認します。
- async関数内のtime.sleepや同期HTTP呼び出しを避けます。
- 同時実行数をSemaphoreなどで制限します。
- Python 3.11以降のTaskGroupは関連Taskの失敗と終了をまとめて管理できます。

# 6. 注意点

awaitを書いても、呼び先の中で同期処理が長く動くとイベントループが止まります。gatherで一つが失敗した時、他の処理が自動的にすべて停止するとは限りません。キャンセル時にCancelledErrorを不用意に握りつぶさないようにします。
