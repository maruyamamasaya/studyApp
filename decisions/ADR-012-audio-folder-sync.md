# ADR-012: 制作物フォルダの管理JSONから自動紐付けと差し替えを行う

status: accepted
updated: 2026-10-02
supersedes: ADR-011

ユーザーは記事ごとの音声選択を不要とし、制作ツールで保持するtrackIDと記事IDの対応を使う方針を指定した。同じtrackIDの音声データは制作側で差し替えられる。

ユーザーが一度許可したiCloud Drive等のフォルダをbookmarkで保持し、起動・アクティブ復帰・手動同期で*.track.jsonを走査する。各JSONのarticleIDで自動紐付け、trackIDで追加/更新を判断する。既存trackIDの記事IDを変更する入力は拒否する。別の声/独立した版は別trackIDにできる。

全入力を検証してから新音声コピーと一覧を確定し、失敗時は旧データを維持する。音声hashが同じなら位置を維持し、異なる場合は先頭へ戻す。再生中の更新は停止して再生を案内する。削除は伝播せず旧コピーを保持する。iCloud常時監視やバックグラウンド定期同期は行わない。

ユーザー回答により制作ツールはこれから用意し、VOICEVOXのAPIまたはソフトを使う方針と確認した。制作ツールがこの受け入れ契約のtrackID/articleID/audioFileを出力・保持する。MacでのビルドとFile Provider実機確認は未実行。
