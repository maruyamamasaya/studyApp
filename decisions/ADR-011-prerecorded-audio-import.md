# ADR-011: 事前生成音声をファイルから取り込みtrackIDで管理する

status: superseded by ADR-012
updated: 2026-10-02

ユーザーが要約・脚本・音声を事前制作する方針を採用し、iOSアプリ側の受け入れのみ実装するよう依頼した。保存元はiCloudのダウンロード済みファイルを想定する。

既存articleIDを元記事に使い、音声制作物ごとにUUIDのtrackIDを付ける。同じ記事の声違い・改訂版を別トラックとして保持する。手動取り込みはアプリがIDを作り、管理JSONを使う場合は制作側のIDを維持する。重複trackIDは上書きせず拒否する。

ファイル選択でアクセスを許可された音声・台本・JSONをアプリ内へコピーし、再生中はiCloudのアクセス権や配置に依存させない。正本はiCloudに残す。BGMは別ファイルをループ再生し、声だけを倍速にする。生成ツールは後続として、CLIから始められる共通の出力契約をios/AUDIO_IMPORT.mdに定義する。

学習記録の既存JSONへ音声を混ぜず、独立した音声一覧・位置保存とする。音声自体のバックアップは制作側ファイルを保持する運用。Macのビルドと実機確認までは動作確認済みとして扱わない。
