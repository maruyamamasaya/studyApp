# ADR-015: 番組の個人編集を端末側で優先する

status: accepted
updated: 2026-10-05

アプリ内での番組編集を再起動・制作物再同期後にも維持する依頼に基づく。制作JSONは初期取り込みと未編集番組の更新に用いる。名前や内容を編集した番組は全体を端末側優先とし、部分的な同期マージでユーザーの順番や解除を戻さない。曲間のみの変更は既存のgapOverridesを維持する。

既存index v1へoptionalの編集ID・削除IDを追加する。削除IDは同じ制作番組の復活を防ぐ。programsの配列順を表示順とし、新しい番組は末尾へ追加する。端末の空番組は許可するが、制作JSONと再生状態は従来の非空契約を保つ。

編集・削除は音声の実体や位置、聴取済み、RadioSessionを変更しない。再生時点のスナップショットを「続きから聴く」で保持し、「最初から聴く」で編集を反映する。削除した番組の最後の再開状態も残す。番組の個人編集は既存の学習記録バックアップには含めない。制作側に戻すリセット操作や複数端末同期は今回の対象外。
