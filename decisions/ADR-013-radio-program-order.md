# ADR-013: 番組の明示的な再生順とインターバルを保持する

status: accepted
updated: 2026-10-02

ユーザーが約5分の音声を記事の順に流すラジオ構成を希望し、番組管理JSON・標準3秒のインターバル・途中再開を承認した。Macでまとめてテストし、音声機能一式をリモートへcommit/pushする依頼を受けた。

playlistIDとtrackIDs配列を持つ*.playlist.jsonを制作物フォルダから同期する。記事との紐付けはarticleID、音声差し替えはtrackID、番組順は配列で分担する。再生中の順番変更で飛ばないよう、番組開始時のスナップショットを保存する。

インターバルは0〜10秒。BGMと独立した無音PCMのAVAudioPlayerで進行させ、バックグラウンドでTask.sleepやUIタイマーだけに依存しない。一時停止で残り時間を保存し、最後にBGMも停止する。OSの挙動はMac/実機で検証する。

初期版は最後の番組1件を途中再開できる。複数番組の個別再開履歴や聴取時間集計は後続。音声制作ツールは今回の実装対象に含めない。
